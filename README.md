Programmet låter två USB-huvudmöss styra varsin skärm och kan köra i bakgrunden med en ikon vid klockan. Installationsfilen innehåller .NET och kräver inga extra drivrutiner. En vanlig reservmus är valfri.

Version 1.2.5 förbättrar klick och manuell dragning över det valda Comfort-tangentbordet. Om Comfort kör med högre behörighet används vanlig Windows-mus över tangentbordet, från anslutna möss, tills knappen släppts och pekaren lämnat tangentbordet. Huvudstyrningen återupptas därefter på samma huvudmus. Godkänt tangentbordsstöd kan behålla filtreringen över det verifierade Comfort-tangentbordet.

Programmet förhindrar att små rörelser från en vanlig mus avbryter huvudmusen. Klicka med den vanliga musen för att ta över. Tillfälliga avbrott återansluter till samma huvudmus utan ett nytt aktiveringsklick; manuella pauser respekteras.

Välj Windows skärmtangentbord eller ett redan öppet tangentbordsfönster i fliken Skärmtangentbord. Comfort Keys Suite har särskilt stöd för flytt och storlek. Varje tangentbord minns sin plats, storlek och sitt läge separat på varje skärm. Uppdateringar ersätter samma installation och behåller inställningarna.

Välj enheter och skärmar och genomför första provet på varje ny dator. Windows 10 22H2/Windows 11 x64 stöds. Installationsfilen är inte digitalt signerad; Windows kan visa okänd utgivare.

137 kodtester och startprovet passerar. Pekarträffen har verifierats mot det riktiga Comfort-tangentbordet. Den fysiska dragningen med användarens huvudmus är ännu inte verifierad.

Övriga instruktioner finns på [pawu.se/headmouse-manager](https://pawu.se/headmouse-manager/). Använd länkarna ovan för den senaste versionen på GitHub.

Releaser innehåller installationsfil, portabel version, kom-igång-guide och SHA-256. Webbplatsens privata källkod och användarens personliga enhetsinställningar ingår inte här.
