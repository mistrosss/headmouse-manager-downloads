# HeadMouse Manager – nedladdningar

Här publiceras installationsfiler för HeadMouse Manager för Windows.

**Nedladdningssida och instruktioner:** https://pawu.se/headmouse-manager/

Programmet låter två USB-huvudmöss styra varsin skärm och kan köra i bakgrunden med en ikon vid klockan. Installationsfilen innehåller .NET och kräver inga extra drivrutiner.

Version 1.2 minns Windows skärmtangentbords plats, storlek och öppna/minimerade/stängda läge separat på varje skärm. Godkänn tangentbordsstödet en gång efter programstart så fungerar huvudmusstyrningen även över tangentbordet. Flytta och ändra storlek när du vill; ingen paus behövs. Uppdateringar ersätter samma installation och behåller inställningarna.

Välj enheter och skärmar och genomför första provet på varje ny dator. Installationsfilen är inte digitalt signerad; Windows kan visa okänd utgivare.

Releaser innehåller installationsfil, kom-igång-guide och SHA-256. Webbplatsens privata källkod och användarens personliga enhetsinställningar ingår inte här.
